# American English Accent Trainer

A 6-week, 1-hour-per-day General American pronunciation and connected-speech training PWA.

## Learning loop
HEAR → IDENTIFY → COPY → COMPARE → USE → PROVE → REVIEW

## Core systems
- Day 0 diagnostic
- 42-day spiral curriculum
- Daily Stress Gym
- Reduction Lab
- Audio model playback
- Learner recording/playback
- Mastery tracking
- Weekly audits
- Day 42 final reassessment
- Day 49 and Day 63 retention checks

## Mastery states
NEW → LEARNING → ACCURATE → AUTOMATIC → RETAINED

## Initial implementation scope
Phase 1 establishes the app shell, content engine, Day 0 diagnostic, Day 1 lesson, Stress Gym, Reduction Lab scaffolding, and local mastery/progress storage.
